## Fixed during the baseline

| Problem | Cause | Fix |
| --- | --- | --- |
| `test:coverage` failed: `platform.e2e-spec.ts` `beforeAll` timed out at 30 s | The combined run executes the unit and e2e projects at once, instrumented. That suite's `beforeAll` signs up two staff users and publishes four structured items through the full review workflow. It passes alone (e2e-only run) | `vitest.config.e2e.ts`: `hookTimeout` 30 s → 90 s, `testTimeout` 20 s → 30 s |
| `RATE_LIMIT_ENABLED=false pnpm dev` (and `EMAIL_PROVIDER=log pnpm dev`) had no effect | Turborepo 2 runs tasks in strict env mode and drops undeclared variables, so the API read only `apps/api/.env` | `turbo.json`: `dev` task gets `passThroughEnv: ["*"]` (dev only; cached tasks keep strict mode) |

## Notes for repeat runs

- The website's Playwright suite signs up about 15 users per run. The sign-up limit is 10/hour
  per IP, so run the local API with `RATE_LIMIT_ENABLED=false` (refused in production).
- E2E needs `TEST_DATABASE_URL` pointing at the disposable `preconception_e2e` database.
