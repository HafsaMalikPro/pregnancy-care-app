## Fixed during the baseline

| Problem | Cause | Fix |
| --- | --- | --- |
| `topics.spec.ts` shopping list: `check()` on the first checkbox failed | Checked items move to the end of the list, so `.first()` pointed at a different, unchecked item after the click. `check()` also asserts synchronously, before the API has saved the item | The test pins the item by id, then clicks and asserts `toBeChecked()` |
| Shopping-list checkbox waited for the API before ticking | No optimistic update | `ShoppingListPanel.toggle` ticks immediately and reverts on error |
| 4 tests failed at sign-up with "Too many requests" | Sign-up is limited to 10/hour per IP; the suite signs up about 15 users | Run the local API with `RATE_LIMIT_ENABLED=false` (the backend's `turbo.json` now passes it through to `pnpm dev`) |
